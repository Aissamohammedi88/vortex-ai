## 🧬 Qu'est-ce que VORTEX ?

**Vortex** n'est pas une énième API branchée sur les serveurs d'OpenAI ou d'Anthropic. C'est un **écosystème d'Intelligence Artificielle Souveraine** conçu pour fonctionner en autonomie totale sur ta propre infrastructure.

Inspiré par les principes du Manifeste Nexus Quantum, Vortex repousse les limites de l'IA locale en combinant :
- **L'inférence locale** (via des orchestrateurs comme Ollama, PyTorch, ONNX).
- **La mémoire persistante** (le concept OMEGA de résonance cognitive).
- **Le calcul déterministe** (via des modules satellites comme PROTON-CALC pour éliminer les hallucinations mathématiques).
- **La génération de code et de systèmes** (via NEXUS OS Builder).

**"Data without type is a rumor. Data with type is a truth."**

## 🛡️ Protocole de Souveraineté

Vortex applique le dogme de la **Souveraineté Absolue** :
1. **Zéro Télémétrie** : Aucune de tes données, prompts ou conversations ne quitte ta machine.
2. **Zéro Vendor Lock-in** : Le système est open-source et peut être forké, modifié et déployé sur n'importe quel serveur.
3. **Zéro Hallucination Critique** : Les modules sensibles (mathématiques, génération de code système) sont vérifiés par des validateurs déterministes (AST, Polinascience), et non par la probabilité statistique d'un réseau de neurones.
